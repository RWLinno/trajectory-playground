RESEARCH CONTEXT · REVIEWED 14 OCT 2026

A useful intuition. A deliberately small claim.

Diffusion → action sequences

Diffusion Policy (2023/2024) combines multimodal action generation, visual conditioning and receding-horizon control. Here we isolate distribution learning in a single coefficient; there are no observations or closed-loop actions.

Flow matching → generalist policies

π₀ (2024) uses a vision-language backbone and a flow-matching action expert. π₀.₅ (2025) studies open-world generalization. Neither flow matching nor VLA is implemented here.

What a fair next experiment needs

Start with a two-component mixture and a randomized geometric baseline. Match samples and inference budgets; test asymmetric modes and held-out obstacles across several training seeds. Report validity and coverage together.

Best use: an interactive teaching project.

The held-out geometric valid rate is 98.33% for diffusion versus 0% for MLP (128 conditions × 64 samples; one training seed). This intentionally symmetric problem makes MSE averaging fail. It does not establish an advantage over other generative methods or robot task success.

WHAT TO NOTICE

A mean is not always
a useful answer.

The training set contains equally many routes above and below the obstacle. Squared-error regression is rewarded for predicting their average—even when that average collides.

Diffusion learns a distribution over a path’s bend. Sampling can recover both routes instead of merging them. A spread of lines is not enough: only collision-free paths count toward valid route coverage.

Switch the scene, draw another subset, and compare valid paths with route coverage. Failed samples are kept in the display.

UNDER THE HOOD

Small enough to understand.
Honest enough to reproduce.

What is learned?

Each path is a straight start-to-goal line plus a sine-shaped bend. The networks predict or sample one bend coefficient, conditioned on obstacle radius, horizontal position and endpoint slope. The diffusion model uses 64 denoising steps. This deliberately restricted family makes the averaging problem visible.

Are these live model predictions?

No. The browser displays 64 actual, unfiltered samples per model for each of nine saved scenes, generated after training. Resample selects a new subset from that bank. Moving between presets selects another saved condition. There is no server or GPU behind the page.

What does “valid” mean?

A point path stays in the square workspace and avoids the circle. We check entire line segments, not just waypoints. Valid routes counts whether at least one valid sample passes above and below. These are geometric checks, not guarantees about a robot’s joints, dynamics or safety.

What does this experiment not prove?

It is a single-training-seed teaching experiment with synthetic, symmetric demonstrations. Both routes are built into the path family. It does not establish diffusion’s superiority over other generative models, solve arbitrary maps, or measure real robot performance. A two-component mixture or simple randomized planner could also solve this example.
